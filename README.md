# torneo1v1real

Proyecto [Next.js](https://nextjs.org) (App Router) con [Tailwind CSS](https://tailwindcss.com), gestionado con [pnpm](https://pnpm.io).

## Getting Started

Instala las dependencias:

```bash
pnpm install
```

Levanta el servidor de desarrollo:

```bash
pnpm dev
```

Abre [http://localhost:3000](http://localhost:3000) para ver el resultado.

Edita `src/app/page.tsx` para empezar a modificar la página; se actualiza automáticamente.

## Scripts

- `pnpm dev` — servidor de desarrollo
- `pnpm build` — build de producción
- `pnpm start` — levanta el build de producción
- `pnpm lint` — linting con ESLint
